# SleepWarp (Updated)

SleepWarp accelerates time while players sleep instead of skipping directly to day. On multiplayer servers, the acceleration scales with the number of players asleep. It can also simulate random block, weather, block-entity, and mob ticks while time advances (all configurable).

## NeoForge build

This branch targets **Minecraft 26.1.2** with **NeoForge 26.1.2**. Install the built `sleepwarp-*.jar` on a NeoForge 26.1.2 installation. SleepWarp is server-side logic and does not need to be installed by remote clients.

The mod's common configuration is generated by NeoForge in the `sleepwarp-common.toml` config file. Its options control sleep requirements, the action bar, world simulation, and acceleration tuning.

The GitHub Actions workflow builds the mod on every push and pull request and uploads the compiled jar as a workflow artifact. Pushing a version tag beginning with `v` (for example, `v2.13.0+26.1.2-neoforge`) runs the same build and creates a GitHub release containing that exact verified jar.
